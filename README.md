## 📌 О проекте
Вданном проекте рассмотрен полный цикл: от сбора и очистки данных до визуализации и выводов.
Я решила исследовать каталог Netflix, чтобы понять:
*   В каком году было выпущено больше всего контента?
*   Какие возрастные рейтинги и жанры самые популярные?
*   Какие страны производят больше всего фильмов и сериалов?

## 🗂️ Источник данных
**Датасет:** [Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows/data) с Kaggle.
  

## 🛠️ Процесс работы:
В этом проекте я сделала ставку на **SQL** как на основной инструмент для очистки, трансформации и анализа данных. Excel использовался только для первоначального просмотра структуры.

### 1. Первичный осмотр и стратегия (Excel)
*   Выявила ряд проблем: объединённые жанры и страны в одной ячейке, пропуски и многие другие проблемы.

### 2. Очистка данных и анализ (SQL)
*   Обработка пропусков — удалила записи с отсутствующими атрибутами, не влияющие на репрезентативность выборки.
*   Нормализация поля «Страна производства» — для записей с несколькими странами оставила только первое значение, что обеспечивает однозначность географической принадлежности.
*   Приведение формата даты — текстовое представление даты преобразовала в тип DATE.
*   Когда данные были очищены и приведены в порядок, я приступила к анализу, чтобы ответить на ключевые вопросы исследования.

### 4. Визуализация (Power BI)
*   Подключение: В Power BI экспортировала CSV-файл.
Каждая визуализация на дашборде — это ответ на вопрос, который я уже нашла с помощью SQL. Power BI стал инструментом для упаковки этих инсайтов в наглядный и интерактивный интерфейс.

(P.S. Забыла про существование срезов ☹️🔫)

## 📈 Ключевые выводы
*   Динамика выпуска - Наибольший рост производства наблюдался в период с 2016 по 2018 год, когда ежегодный выпуск превысил 1000 единиц контента. После 2018 года зафиксировано умеренное снижение количества новых релизов.
*   Лидер по странам: США — абсолютный лидер по производству, создав почти в 3 раза больше контента, чем следующая за ней Индия.
*   Популярный рейтинг: Самый распространенный возрастной рейтинг — TV-MA (для взрослой аудитории).
*   Различие жанров: Для фильмов и сериалов самыми популярными жанрами являются драмы и комедии.
