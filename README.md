## 📌 О проекте
Полный цикл анализа данных: от первичного осмотра сырых данных до дашборда с выводами. Каталог Netflix исследовался, чтобы ответить на три вопроса:
*   В каком году было выпущено больше всего контента?
*   Какие возрастные рейтинги и жанры самые популярные?
*   Какие страны производят больше всего фильмов и сериалов?

## 🗂️ Источник данных
**Датасет:** [Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows/data) с Kaggle.
  

## 🛠️ Процесс работы:
В этом проекте я сделала ставку на **SQL** как на основной инструмент для очистки, трансформации и анализа данных. Excel использовался только для первоначального просмотра структуры.

### 1. Первичный осмотр и стратегия (Excel)
Просмотр структуры данных выявил основные проблемы: объединённые жанры в одной ячейке, пропуски в поле «страна» и неоднородный формат длительности (минуты у фильмов, сезоны у сериалов). Часть предварительного приведения формата сделана через Power Query 

### 2. Проверка качества данных (SQL)
*   Проверка на пропуски по всем 10 полям — обнаружено 2 пропуска в поле country.
*   Проверка уникальности show_id и title — дублей не найдено.
*   Проверка на неоднородность категориальных значений (type, rating) — регистр и написание единообразны.

### 3. Очистка данных (SQL)
* Пропуски в стране — вручную восстановлены по 2 записям (Eyes of the Thief, D.P.) на основе данных о фильме/сериале.
* Нормализация поля «Жанр» — многозначные строки разбиты на отдельные значения средствами SQL (STRING_TO_ARRAY + UNNEST), что позволило корректно посчитать частоту каждого жанра по отдельности, а не по их комбинациям.

### 4. Анализ (SQL)
Некоторые расчеты были добавлены позже (когда пересматривала работу, решила, что нужно добавить что-то интересное😋):
* средняя длительность фильмов и сериалов по годам;
* доля сериалов, не получивших продолжения (только 1 сезон), по годам.


### 5. Визуализация (Power BI)
Очищенные данные выгружены из SQL в CSV и подключены в Power BI. Каждый элемент дашборда — визуализация одного из инсайтов, найденных на этапе SQL-анализа.

(P.S. Забыла про существование срезов ☹️🔫)

## 📈 Ключевые выводы
*   Динамика выпуска: пик пришёлся на 2016–2018 годы — в среднем 946 единиц контента в год. После 2018 года — умеренное снижение числа новых релизов.
*   Лидер по странам: США — абсолютный лидер (3201 единица контента), почти втрое опережает Индию (1008 единиц).
*   Возрастной рейтинг: самый распространённый — TV-MA (контент для взрослой аудитории).
*   Различие жанров: Для фильмов и сериалов самыми популярными жанрами являются драмы и комедии.

## 📈 Дополнительные инсайты
  * Средняя длительность фильмов росла вплоть до 1964 года, достигнув пикового значения в 200 минут, после чего началось постепенное снижение.
  * Для сериалов до 2000 года чёткого тренда по длительности не прослеживается; с 2000 по 2010 год среднее число сезонов держалось около 3, позже снизилось до 2 — похоже на переход индустрии к более коротким сериальным форматам.


## ⚠️ Ограничения данных
* При отсутствии страны-производителя для 2 записей значение восстановлено вручную по внешним источникам, а не выведено из самих данных.
* Анализ по жанрам учитывает каждый жанр отдельно (после разбивки многозначного поля) — сумма по жанрам превышает общее число записей, так как один тайтл может относиться к нескольким жанрам одновременно.
